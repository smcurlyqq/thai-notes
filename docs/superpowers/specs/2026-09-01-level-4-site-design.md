# Thai Notes Level 4 與多語言導覽設計

日期：2026-09-01（Asia/Taipei）

## 目標

把目前只有 Level 3 的靜態筆記站，改成可長期擴充到 Level 3–9 的兩層導覽網站，並一次完成 Level 4 第 1–8 課及 Exam Review。

本次也同步整理 Level 3：所有既有內容補上韓文，所有泰文補齊羅馬讀音，並讓課文翻譯採一致的顯示方式。

## 已確認需求

- 採用 A 方案：所有 Level 首頁 → 各 Level 首頁 → 課程或考前筆記。
- 所有 Level 首頁只突出目前可閱讀的 Level 3、4；Level 5–9 以精簡的「之後加入 / Coming next」呈現。
- 首頁、卡片、按鈕、麵包屑與操作說明固定顯示繁體中文與英文。
- 課程內容預設顯示泰文、羅馬讀音及繁體中文。
- 使用同一個按鈕顯示或隱藏英文、日文、韓文翻譯。
- 所有泰文內容都必須有羅馬讀音，且羅馬讀音永遠顯示，不受語言按鈕影響。
- Level 3 與 Level 4 的課程頁、考前筆記頁都套用相同規則。
- 目前沒有入口的舊版 `test2.html` 仍保留，並一併補上韓文、羅馬讀音及語言切換。
- 現有公開網址與舊書籤不得失效。

## 非目標

- 不加入登入、帳號、資料庫、後台或追蹤分析。
- 不導入框架、套件管理器或建置流程。
- 不建立 Level 5–9 的空白課程頁；只在上層首頁顯示未來 Level 標示。
- 不改成單頁應用程式，也不把 Level 切換做成容易和頁內導覽混淆的 tab。

目前位於 repository 根目錄的 Level 3 內容網址改成相容轉址頁，例如：

- `/l1-2.html` → `/level-3/l1-2.html`
- `/test4-notes.html` → `/level-3/test4-notes.html`

轉址需保留 query string 與 hash。沒有 JavaScript 時仍提供 meta refresh 與可點擊的中英雙語備援連結。

## 頁面設計

### 所有 Level 首頁

- 標題為 `Thai Notes`。
- 固定顯示「選擇目前的學習階段 / Choose your current level」。
- Level 3、4 使用大型可點擊卡片，顯示課程數與 Exam Review 數量。
- Level 5–9 使用小型、不可點擊的虛線標籤，不讓未完成內容搶走主要視覺。
- Level 3 沿用藍色主色；Level 4 可使用紅色上框或另一個清楚但協調的識別色。

### Level 首頁

- 頂端提供「所有 Level / All Levels」返回連結。
- 顯示四張課程卡：Lessons 1–2、3–4、5–6、7–8。
- 每張卡顯示泰文課次、羅馬讀音、中文主題及英文主題。
- Exam Review 使用紅色識別，與一般課程卡保持同一套卡片語言但有清楚層級差異。

### 課程頁與 Exam Review

- 頂端使用麵包屑：所有 Level / All Levels → Level → Lessons 或 Exam Review。
- 課程內部維持既有筆記形式，包括來源內容實際具有的閱讀、對話／獨白、寫作、單字、文法與 Key Points。
- Level 3 現有泰文課文內容保持不變；只補語言、羅馬讀音、導覽與必要的結構標記。
- Level 4 依使用者提供的本機來源資料整理成相同深度的筆記。來源檔只在本機使用，不加入 repository，也不在公開頁面顯示來源檔名、浮水印或其他檔案資訊。
- 課次與學習所需的頁碼標示可以保留；不額外放置教材宣傳或來源歸屬文案。

## 語言顯示規則

### 固定顯示

- 泰文原文。
- 每段泰文對應的羅馬讀音。
- 繁體中文翻譯或說明。
- 網站操作介面的英文說明。

### 點按後顯示

- 英文內容翻譯。
- 日文內容翻譯。
- 韓文內容翻譯。

按鈕預設文案為：

`顯示 EN · JP · KR / Show EN · JP · KR`

展開後文案為：

`隱藏 EN · JP · KR / Hide EN · JP · KR`

每次開啟新頁都回到預設的中文狀態，不使用 localStorage 記住先前選擇。

### 無 JavaScript 時

頁面先以「所有語言可見」作為安全基線；JavaScript 啟動後立即在 `<html>` 加上 `js` class，再隱藏額外語言並提供切換按鈕。如果 JavaScript 不可用，所有翻譯保持可見，確保內容不會因功能失敗而消失。

## 羅馬讀音規則

- 沿用現有網站的學習者友善格式：拉丁字母、連字號及聲調符號。
- 不改成純 RTGS，也不移除聲調資訊。
- 適用範圍包括課次與泰文標題、課文句子、對話每句、單字、文法型態、文法例句、Key Points 中的泰文及 Exam Review 中的泰文。
- 羅馬讀音緊接在對應泰文之下或旁邊，使用同一個可辨識的藍色斜體樣式。
- 語言切換按鈕不得隱藏羅馬讀音。
- 實作時要校正既有 Level 3 中缺漏或明顯不一致的羅馬讀音，但不任意改換整套拼音系統。

## 共用元件與行為

### `assets/site.css`

集中管理：

- 色彩、字型、間距及卡片基礎樣式。
- 上層 Level 導覽、麵包屑與語言按鈕。
- 羅馬讀音及各語言標記的樣式。
- 手機與桌機斷點。

既有內容頁可保留必要的頁面專屬 inline CSS，避免為了共用樣式進行與本需求無關的大幅重寫。

### `assets/language-toggle.js`

- 尋找頁面上的語言切換按鈕。
- 切換英文、日文、韓文區塊的可見狀態。
- 同步更新按鈕文案、`aria-expanded` 與頁面狀態 class。
- 不儲存跨頁偏好。
- 頁面沒有額外語言內容時不顯示無作用的按鈕。

## 視覺與互動原則

- 延續目前的米白背景、白色卡片、藍灰主色與紅色 Exam Review 識別。
- 主要 Level 卡片、頁內錨點、語言切換與返回連結必須有不同的形狀或重量，避免看起來像同一層級的控制項。
- 使用語意化的 `<nav>`、`<main>`、標題階層、連結與真正的 `<button>`。
- 提供清楚的鍵盤 focus 樣式、足夠色彩對比與觸控尺寸。
- 手機版維持單欄卡片；不使用需要橫向捲動才能操作的主要導覽。
- 列印時隱藏導覽與語言按鈕，但保留當下已顯示的學習內容。

## Level 4 內容範圍

- Lessons 1–2：睡眠與健康。
- Lessons 3–4：國歌、日常禮儀與文化。
- Lessons 5–6：占卜與十二星座性格。
- Lessons 7–8：婚姻問題與不同年齡的愛情。
- Exam Review：涵蓋 Level 4 第 1–8 課的單字、文法、例句與考前重點。

每一組課程頁都需要完整的繁體中文、英文、日文、韓文翻譯與泰文羅馬讀音；不可以留下缺少語言的卡片或只完成部分章節。

## 驗證與錯誤處理

### 自動檢查

- 所有本機相對連結都能找到目標檔案。
- 所有根目錄舊網址都有對應的 Level 3 轉址。
- 所有可翻譯內容區塊都有中文、英文、日文、韓文欄位。
- 所有包含泰文字元的學習內容都有鄰近的羅馬讀音欄位。
- HTML 不包含本機絕對路徑、來源 PDF 檔名或未完成標記。
- 執行 `git diff --check`，避免空白與 patch 格式問題。
- 自動檢查只驗證結構完整性；每一課仍要人工抽查泰文、羅馬讀音與中／英／日／韓翻譯是否語意一致。

### 瀏覽器檢查

- 桌機及手機寬度下檢查所有 Level 首頁、四種課程頁型態與 Exam Review。
- 確認初始狀態只有中文內容翻譯可見。
- 確認按鈕可一次展開及收合 EN／JP／KR，且羅馬讀音始終可見。
- 確認麵包屑、返回連結、課程卡與舊網址轉址均正確。
- 確認沒有文字重疊、截斷、橫向捲動或不可點擊的控制項。

## 驗收標準

1. 根首頁清楚區分 Level 3、4，並以精簡方式預告 Level 5–9。
2. Level 3 的現有內容與舊網址繼續可用。
3. Level 4 第 1–8 課與 Exam Review 全部完成。
4. 所有網站操作說明固定顯示繁體中文與英文。
5. 所有課程內容預設為泰文、羅馬讀音與繁體中文。
6. 所有英文、日文、韓文內容能由單一按鈕顯示及隱藏。
7. 每一段泰文學習內容都有羅馬讀音，沒有語言或章節缺漏。
8. 手機與桌機均可順暢閱讀及操作。
9. repository 維持無建置步驟的純靜態部署方式。

## 發布流程

先在本機完成與驗證，再向 Amber 摘要實際差異。只有 Amber 看過差異並明確同意後，才可 commit 與 push 到 `main`。GitHub Pages 會沿用現有設定自動發布。
