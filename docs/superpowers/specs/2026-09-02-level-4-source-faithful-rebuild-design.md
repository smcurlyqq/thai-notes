# Thai Notes Level 4 原稿忠實重建設計

日期：2026-09-02（Asia/Taipei）

## 問題

目前 Level 4 把教材的主課文與對話濃縮成摘要句，違反 Amber 已確認的「課文照舊」要求。結構稽核雖然通過，卻沒有證明來源內容完整，因而讓摘要版被誤判為完成品並發布。

## 已確認方案

採用「完整課內內容」：第 1–8 課依課本編排順序收錄完整的 `บทสนทนา`／`บทอ่าน`、全部 `คำศัพท์`、全部編號 `หมายเหตุ`、全部 `ไวยากรณ์` 說明與來源例句，以及全部理解、文法、口說、造句練習。不得自行把任何一類排除、濃縮成精選或摘要。兩課一組的獨立複習與最終考前複習沿用獨立 Exam Review scope。

每個泰文學習單位固定包含：

1. 完整且不改寫的泰文原文。
2. 可見的課本印刷頁碼；跨頁項目顯示頁碼範圍。
3. 帶聲調的學習者友善羅馬讀音。
4. 預設顯示的繁體中文翻譯或說明。
5. 按鈕展開的英文、日文及韓文翻譯或說明。

## 來源完整性規則

- 寫作前先建立逐頁 source inventory，記錄課次、頁碼、章節、項目數及原文順序。
- 不得把摘要、改寫或自行合併的句子標為「核心課文／核心對話」。
- 主課文／對話、單字、註解、文法、例句與課內練習都必須逐項對回來源，不得只驗主課文或「非練習內容」。
- 每課每類建立來源 manifest，記錄項目數及依原順序串接的頁碼＋泰文雜湊。
- 發布前由 auditor 比對頁面與 manifest；數量、順序或雜湊任一不符即失敗。
- 結構檢查通過不等於內容完整。發布前還必須產出逐課來源對照報告，並抽查 PDF 原頁。
- 未完成全部八課、翻譯、羅馬讀音及來源對照前，不得稱為完成，也不得發布。

## 頁面結構

沿用現有四個 Level 4 課程網址與視覺系統。每課依序呈現：

1. 課次與主題。
2. 完整課文或完整對話。
3. 完整單字。
4. 課本註解（該課有時）。
5. 課本文法、全部來源例句與課內練習，依實際頁序互相穿插。

所有區塊與區塊內項目都依課本出現順序排列；練習題若穿插在文法中，網站也保留相同位置，後續文法再按原位置接續。

介面固定中英雙語；學習內容預設顯示泰文、羅馬讀音與繁中，EN／JP／KR 仍由同一按鈕控制。

## 驗收

- 第 1–8 課五類課內內容皆有逐頁 source inventory，且所有清單項目完成。
- 每個內容單位都有正確且可見的課本印刷頁碼。
- 頁面內容與 source manifest 的數量、順序及雜湊完全相同。
- 每個泰文單位都有非空、帶聲調的羅馬讀音。
- 每個內容單位都有 `zh-Hant`、`en`、`ja`、`ko`，且沒有跨語系誤貼。
- 全站 auditor、測試與 `git diff --check` 全部通過。
- 用 MBQQ 內建瀏覽器逐頁驗證預設中文、語言切換、桌機與手機版。
- 完成後先向 Amber 報告逐課項目數與實際差異；取得新的明確同意後才 commit、push 與更新 Notion。
