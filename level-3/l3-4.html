ง่ายนิดเดียว
ngâaj nít-diaw
＝ ngâaj mâak mâj jâak ləəj（超簡單、一點也不難）

＝とても簡単、少しも難しくない
= 아주 쉽지만 전혀 어렵지 않습니다
ก็แล้วกัน
kɔ̂-lɛ́ɛw-kan
表示做了決定，常用在要從選項中選擇時
shows the speaker has decided, often when choosing among options
選択肢から決めたことを示す
연설자 의 결정 을 나타냅니다. 종종 선택 중 하나를 선택 할 때
บ้าง
bâng
句尾語助詞，用於想要一串列舉的答案時
final particle, used when you want a list of answers
文末詞、いくつも列挙した答えがほしいとき
마지막 입자, 응답 목록을 원하는 경우 사용
ต่าง ๆ (นานา)
tàang tàang ( naa-naa )
表示還有很多沒提到的東西（「各種、種種」）
indicates many other things not mentioned ("various")
挙げていないものがまだ多い（「様々な」）
언급되지 않은 많은 다른 것을 나타냅니다 ("다양한")
อยู่แล้ว
à-jùu-lɛ́ɛw
表示某人／某物本身就具備此特質，不必再多加什麼（「本來就」）
shows the subject already inherently has the quality ("already/anyway")
もともとその性質を備えている（「もともと」）
해당 주체가 이미 본질적으로 품질을 가지고 있음을 나타냅니다 (" 이미 / 어쨌든")

jàa --- lâ
「就是別…喔」，常用於提醒或命令
"Just don't …", used to remind or order
「〜しないでね」、注意や命令に
"그냥 하지마"...
① ประโยคแสดงสภาพ แบบที่ ๓ (เป็น)
① prà-jòok sà-dɛɛng sà-phâap bɛ̀ɛp thîi sǎam ( pen )
狀態句第3型：prà-thaan + pen + 特質/身分。否定用 mâj châj；用 mâj dâaj pen 表示身分不像別人所想。
Stative type 3: subject + pen + trait/status. Negate with mâj châj; mâj dâaj pen means the status isn't as others thought.
状態文第3型：主語＋pen＋特徴/身分。否定は mâj châj；mâj dâaj pen は人の思うのと違う身分。
정적 유형 3: 주체 + 펜 + 특성/상태. mâj châj로 부정한다. mâj dâaj 펜은 다른 사람들이 생각하는 상태가 아니라는 것을 의미합니다.
② ประโยคแสดงสภาพ แบบที่ ๔ (คือ)
② prà-jòok sà-dɛɛng sà-phâap bɛ̀ɛp thîi sìi ( khʉʉ )
狀態句第4型：prà-thaan + khʉʉ + 介紹/說明。否定用 mâj châj。
Stative type 4: subject + khʉʉ + introduction/explanation. Negate with mâj châj.
状態文第4型：主語＋khʉʉ＋紹介/説明。否定は mâj châj。
정형 4: 주체 + khʉʉ + 소개/ 설명.
③ ประโยคบอกให้ทำ
③ prà-jòok bɔ̀ɔk hâj tham
祈使句：命令 jàa.../hâam.../tɔ̂ng...；請求 kà-rú-naa.../dâaj pròot.../...dâaj mǎj；禁止 hâam...
Imperatives: order (jàa/hâam/tɔ̂ng), request (kà-rú-naa/dâaj pròot/…dâaj mǎj), prohibition (hâam).
命令文：命令 jàa/hâam/tɔ̂ng、依頼 kà-rú-naa/dâaj pròot/…dâaj mǎj、禁止 hâam。
명령 (jàa/hâam/tɔ̂ng), 요청 (kà-rú-naa/dâaj pròot/...dâaj mǎj), 금지 (hâam).
④ การใช้คำซ้ำเพื่อบอกให้ทำ
④ kaan cháj kham sám phʉ̂a bɔ̀ɔk hâj tham
用疊字下指令：動作動詞 + [狀態動詞 + ]，表示「做得更…一點」。
Reduplication to give commands: action verb + [stative verb + ] = "do it more …".
畳語で指示：動作動詞＋[状態動詞＋]＝「もっと〜に」。
명령어를 줄이기 위한 복제: 액션 낱말 + [스테티브 낱말 + ] = "더 많이 하라 ...".
เมื่อกี้ (เมื่อกี๊)
mʉ̂a-kîi ( mʉ̂a kíi )
剛剛、不久前，可放句首或句尾
a short moment ago; can go at the start or end
さっき；文頭・文末どちらも可
잠시 전에, 시작이나 끝에서 갈 수 있습니다
การใช้คำซ้ำ (แดง ๆ)
kaan cháj kham sám ( dɛɛng dɛɛng )
形容詞疊字有兩義：(1)加強語氣 (2)表不確定／約略。
Reduplicated adjectives have two senses: (1) emphasis, (2) approximation/uncertainty.
形容詞の畳語は2つ：(1)強調 (2)おおよそ・不確か。
복제된 자명에는 두 가지 의미가 있습니다. (1) 강조, (2) 근접/불확정성.
เดี๋ยวก่อน
dǐaw-kɔ̀ɔn
「等一下！」
"Wait (a moment)!"
「ちょっと待って！」
"잠깐만 기다려!"
เหรอ
rə̌ə
疑問語助詞，放句尾表驚訝、好奇，情緒比一般問句更強
final question particle showing surprise/curiosity, stronger than a plain question
文末の疑問詞、驚き・好奇を表す（普通の疑問より強い）
마지막 질문 의 의외/ 호기심을 나타내는 입자, 단순한 질문보다 강하다
ไง
ngaj
放句尾，表示「說話者覺得聽者早該知道這資訊」
final particle: the speaker feels the listener should already know this
文末詞：聞き手が当然知っているはずという含み
마지막 입자: 스피커는 듣는 사람이 이미 이것을 알아야 한다고 생각합니다.
① ประโยคแสดงการประสบ แบบที่ ๑ (การรับรู้)
① prà-jòok sà-dɛɛng kaan prà-sòp bɛ̀ɛp thîi nʉ̀ng ( kaan-ráp-rúu )
感知句：prà-thaan + 感知動詞（hěn 看見、jəə 遇見、dâaj rót 嚐到、dâj-klìn 聞到、dâj-jin 聽見）。否定用 mâj。
Perception sentences: subject + perception verb (hěn see, jəə meet, dâaj rót taste, dâj-klìn smell, dâj-jin hear). Negate with mâj.
知覚文：主語＋知覚動詞（見る・出会う・味がする・匂いがする・聞こえる）。否定は mâj。
인식 문장: 주체 + 인식 동사 (hěn see, jəə meet, dâaj rót taste, dâj-klìn smell, dâj-jin hear).
เห็น ดู มอง ได้รส ชิม ได้กลิ่น ดม ได้ยิน ฟัง
hěn duu mɔɔng dâaj rót chim dâj-klìn dom dâj-jin fang
有些感知動詞對應「刻意做的動作動詞」：hěn→duu/mɔɔng、dâaj rót→chim、dâj-klìn→dom、dâj-jin→fang。
Some perception verbs pair with deliberate action verbs: hěn→duu/mɔɔng (watch), dâaj rót→chim (taste), dâj-klìn→dom (sniff), dâj-jin→fang (listen).
知覚動詞は意図的な動作動詞と対：見える→見る、味がする→味わう、匂う→嗅ぐ、聞こえる→聞く。
일부 인식 낱말은 의도적인 행동 낱말과 결합한다: hěn→duu/mɔɔng (관), dâaj rót→chim (맛), dâj-klìn→dom (취), dâj-jin→fang (음).
③ ประโยคแสดงการประสบ แบบที่ ๒ (ความรู้สึก)
③ prà-jòok sà-dɛɛng kaan prà-sòp bɛ̀ɛp thîi sɔ̌ɔng ( khwaam-rúu-sʉ̀k )
感受句：prà-thaan + 感受詞（sâw 難過、dii-jaj 開心、kròot 生氣）。否定 mâj；用 mâj dâaj 表感受不如別人所想。
Feeling sentences: subject + feeling word (sâw sad, dii-jaj glad, kròot angry). Negate with mâj; mâj dâaj = the feeling isn't as others thought.
感情文：主語＋感情語（悲しい・うれしい・怒る）。否定は mâj；mâj dâaj は思うのと違う感情。
감정 문장: 주체 + 감정 단어 (sâw sad, dii-jaj glad, kròot angry). mâj로 부정; mâj dâaj = 감정은 다른 사람들이 생각하는 것과는 다릅니다.
