文法與用法Grammar and usage

ง่ายนิดเดียว
ngâaj nít-diaw
= ngâaj mâak 超簡單、一點都不難。
= very easy, not hard at all.
＝とても簡単、少しも難しくない。
= 아주 쉽지만, 어렵지 않습니다.
ก็แล้วกัน
kɔ̂-lɛ́ɛw-kan
做了決定（尤其有選項要選時）用。
used when making a decision among options.
選択肢の
선택권 중 결정을 내릴 때 사용된다.
บ้าง
bâng
句尾語助詞：想要「一串列舉」的答案。
final particle: asking for a list of answers.
文末助詞：いろいろ列挙した答えを求める。
마지막 입자: 답변 목록을 요청합니다.
ต่าง ๆ นานา
tàang tàang naa-naa
表示還有很多沒提到的東西。
various; and many more not mentioned.
いろいろな；他にもたくさんある。
여러 가지가 있고, 언급되지 않은 많은 것들이 있습니다.
อยู่แล้ว
à-jùu-lɛ́ɛw
本來就具備此特質、不必再多加。
already so by nature.
もともとそうである、言うまでもなく。
이미 자연적으로 그렇습니다.
อย่า ล่ะ
jàa lâ
Just don't…；提醒或叮嚀。
Just don't…; a reminder.
〜しないでね；念押し・注意。
그냥 하지 말아요..
เป็น
pen
否定：一般用 mâj châj (mâi-châi)；用 mâj dâaj pen 表示「不像別人想的那樣」。
Neg: usually mâj châj; mâj dâaj pen = 'not as assumed'.
否定は普通 mâj châj；mâj dâaj pen＝「思われているのと違う」。
부정: 일반적으로 mâj châj; mâj dâaj pen = '가설된 바가 아니다'.
คือ
khʉʉ
pen =特質/身分； khʉʉ =下定義、指明「就是那個」。
pen = quality/status; khʉʉ = defines / identifies 'it is that one'.
pen＝性質・身分；khʉʉ＝定義・特定「まさにそれ」。
pen = 품질/상태; khʉʉ = 정의 / 식별 '그것이 바로 그것이다'.
อย่าโกหกฉัน นะ สิ กรุณา ได้โปรด บอกความจริง ห้ามโกหกฉัน
jàa koo-hòk chǎn ná sì kà-rú-naa dâaj pròot bɔ̀ɔk khwaam-jing hâam koo-hòk chǎn
三種語氣。
3 tones: command / request / prohibition.
3つの語気：命令・依頼・禁止。
3 음: 명령 / 요청 / 금지.
คำซ้ำ
kham sám
動作動詞 + [狀態動詞 + ] = 「…得更…一點」。
verb + [stative verb + ] = do it more…
動詞＋[状態動詞＋]＝もっと〜して。
동사 + [정상 동사 + ] = 더 많이 해...
เมื่อกี้ เมื่อกี๊
mʉ̂a-kîi mʉ̂a kíi
剛剛、不久前；句首或句尾。
a moment ago; sentence-initial or final.
さっき、少し前；文頭または文末。
몇 분 전에, 문장 시작 또는 마지막.
แดง ๆ
dɛɛng dɛɛng
兩義：① 加強語氣 ② 表約略/不確定。
two senses: ① emphasis ② approximate / vague.
二つの意味：①強調 ②およそ・あいまい。
두 감각: 1 강조 2 대략 / 모호.
เดี๋ยวก่อน
dǐaw-kɔ̀ɔn
等一下！
Wait a moment!
ちょっと待って！
잠깐만!
เหรอ
rə̌ə
句尾疑問語助詞，表驚訝/好奇。
final question particle: surprise / curiosity.
文末疑問助詞：驚き・好奇。
마지막 질문 부분: 놀라움 / 호기심.
ไง
ngaj
句尾；表示「這你早該知道了」。
final particle: 'you should already know this'.
文末助詞：「もう分かっているはず」。
마지막 입자: "당신은 이미 알고 있어야 합니다".
เห็น เจอ ได้รส ได้กลิ่น ได้ยิน
hěn jəə dâaj rót dâj-klìn dâj-jin
感知動詞：hěn看見、jəə遇見、dâaj rót嚐到、dâj-klìn聞到、dâj-jin聽見。
Perception verbs: see / meet / taste / smell / hear.
知覚動詞：見る・会う・味がする・匂う・聞こえる。
인식 낱말: 보기 / 만나 / 맛 / 냄새 / 듣기.
เห็น ดู มอง ได้รส ชิม ได้กลิ่น ดม ได้ยิน ฟัง
hěn duu mɔɔng dâaj rót chim dâj-klìn dom dâj-jin fang
非刻意(感知) → 刻意(動作)。
involuntary perception → deliberate action.
無意識の知覚→意図的な動作。
자발적인 인식 → 의도적인 행동.
ไม่ ไม่ได้
mâj mâj dâaj
mâj +動作=刻意不做； mâj dâaj +動作=①跟別人想的不同 ②過去沒發生。
mâj = won't (deliberate); mâj dâaj = not as assumed / didn't happen.
mâj＝意図的にしない；mâj dâaj＝思われたのと違う・起こらなかった。
mâj = 의도하지 않음; mâj dâaj = 예상치 못한 / 일어나지 않았다.
เศร้า ดีใจ โกรธ ไม่ได้
sâw dii-jaj kròot mâj dâaj
感受詞：sâw難過、dii-jaj開心、kròot生氣。用 mâj dâaj 表示「感受跟別人想的不同」。
Emotion verbs; mâj dâaj = the feeling isn't as thought.
感情動詞；mâj dâaj＝その感情は思われたのと違う。
감정verb: mâj dâaj = 감정은 생각만큼은 아닙니다.
