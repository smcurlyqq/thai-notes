文法與用法Grammar and usage

เผื่อ
phʉ̀a
以防、萬一 (in case)。
in case; just in case.
念のため、〜するといけないから。
경우에 따라, 경우에 따라.
ไหว
wǎj
體力上做得到/做不到某事。
to be physically able to (do sth).
体力的に〜できる（できない）。
신체적으로 할 수 있는 것 (sth)
นาน ๆ ที
naan naan thii
偶爾、久久一次。
once in a while.
たまに、ごくたまに。
가끔씩.
เยี่ยมเลย
jîam ləəj
太棒了！
That's great!
すごい！最高！
멋져요!
ฝาก ให้
fàak hâj
fàak＝拜託別人幫自己做；hâj＝(口語)幫某人做。
fàak = ask someone to do sth for you; hâj = do sth for someone.
fàak＝人に頼んで〜してもらう；hâj＝人のために〜してあげる。
fàak = 누군가에게 당신을 위해 sth를 부탁하고 hâj = 누군가에게 sth를 해.
และ กับ แล้ว ก็
lɛ́ kàp lɛ́ɛw kɔ̂
lɛ́和／kàp跟…一起／lɛ́ɛw…kɔ̂ 先…然後。
lɛ́ and / kàp with / lɛ́ɛw…kɔ̂ …then…
lɛ́＝〜と／kàp＝〜と一緒に／lɛ́ɛw…kɔ̂＝まず…それから。
그리고, 그리고, 그리고, 그리고, 그리고, 그리고...
แต่ แต่ว่า ถึง แต่ ก็
tɛ̀ɛ tɛ̀ɛ-wâa thʉ̌ng tɛ̀ɛ kɔ̂
但是／然而／雖然…但還是…。
but / however / although…, still…
tɛ̀ɛ＝しかし／tɛ̀ɛ-wâa＝でも／thʉ̌ng…tɛ̀ɛ…kɔ̂＝〜だが、それでも。
하지만, 그럼에도 불구하고...
เช่น ได้แก่
chên dâaj-kɛ̀ɛ
chên＝舉「部分」例子；dâaj-kɛ̀ɛ＝舉「全部/明確」的例子。
chên = some examples (more exist); dâaj-kɛ̀ɛ = a full / explicit list.
chên＝例示（他にもある）；dâaj-kɛ̀ɛ＝すべて・明確な列挙。
chên = 몇 가지 예제 (더 많은 예제들이 존재한다); dâaj-kɛ̀ɛ = 완전한 / 명시적인 목록.
การ
kaan
動作動詞 → 名詞。
prefix kaan-: action verb → noun (nominalizer).
接頭辞 kaan-：動作動詞→名詞化。
앞음 kaan-: 행동 동역자 → 명명 (명명자).
แต่ละ
tɛ̀ɛ-lá
各、每個；永遠放在量詞前面。
each; always before a classifier.
それぞれ、各〜；必ず類別詞の前。
각각; 항상 분류자 앞에
รู้แต่ว่า
rúu tɛ̀ɛ-wâa
只知道…。
only know that…
ただ…だけは分かる。
그냥 아는 건...
โชคดี
chôok-dii
幸運地。
luckily; fortunately.
幸いにも、運よく。
다행히도, 다행히도
จากเหตุการณ์นี้
jàak hèet-kaan níi
從這件事。
from this event.
この出来事から。
이 사건에서
หรือ หรือไม่ก็
rʉ̌ʉ rʉ̌ʉ-màj kɔ̂
rʉ̌ʉ＝或；rʉ̌ʉ-màj kɔ̂＝不然就。
rʉ̌ʉ = or; rʉ̌ʉ-màj kɔ̂ = or else.
rʉ̌ʉ＝または；rʉ̌ʉ-màj kɔ̂＝さもなければ。
rʉ̌ʉ = 또는; rʉ̌ʉ-màj kɔ̂ = 또는.
ก็เลย จึง เพราะฉะนั้น จึง เพราะ
kɔ̂ ləəj jʉng phrɔ́-chà-nán jʉng phrɔ́
kɔ̂ ləəj(口語)／jʉng(較正式)／phrɔ́-chà-nán…jʉng(書面)／phrɔ́(放原因句)。
kɔ̂ ləəj (colloq.) / jʉng (formal) / phrɔ́-chà-nán…jʉng (written); phrɔ́ in the reason clause.
kɔ̂ ləəj（口語）／jʉng（やや書面）／phrɔ́-chà-nán…jʉng（書面）；phrɔ́ は理由節に置く。
kɔ̂ ləəj (colloq.) / jʉng (formal) / phrɔ́-chà-nán...jʉng (written); phrɔ́의 이유 구항에서.
ยกเว้น นอกจาก
jók-wén nɔ̂ɔk-jàak
jók-wén＝除…之外(其他照常)；nɔ̂ɔk-jàak＝除了…(常用否定句)。
jók-wén = except (the norm continues); nɔ̂ɔk-jàak = besides / except (often with negatives).
jók-wén＝〜を除いて（他は通常通り）；nɔ̂ɔk-jàak＝〜以外（否定文でよく使う）。
jók-wén = 예외 (규칙은 계속된다); nɔ̂ɔk-jàak = 게다가 / 예외 (일반적으로 부정적).
ความ
khwaam
狀態/心理動詞 → 抽象名詞。
prefix khwaam-: stative / mental verb → abstract noun.
接頭辞 khwaam-：状態・心理動詞→抽象名詞化。
앞음 Khwaam-: 정적 / 정신적 동사 → 추상적 명자.

例句Examples

เอาร่มไปด้วย เผื่อฝนตก
aw rôm paj dûaj phʉ̀a fǒn-tòk
帶傘去，以防下雨
Take an umbrella in case it rains.
雨が降るといけないから傘を持って行って。
비가 올 경우에 대비해 우산을 가져가세요.
เหนื่อยมาก ล้างรถไม่ไหวแล้ว
nʉ̀aj mâak láang-rót mâj wǎj lɛ́ɛw

I'm too tired, I can't wash the car anymore.
疲れすぎて、もう洗車できない。
너무 피곤해서 더 이상 차를 씻을 수 없어요.

가끔 여행만 할 수 있어요.

พ่อกลับบ้าน แล้วก็อาบน้ำ
phɔ̂ɔ klàp-bâan lɛ́ɛw-kɔ̂ɔ àap-náam
爸回家，然後洗澡
Dad came home and then showered.
父は帰宅して、それからシャワーを浴びた。
아빠가 집에 와서 샤워를 했습니다.
ถึงเขามีงานเยอะ แต่ก็มีเวลาให้ครอบครัว
thʉ̌ng khǎw mii ngaan jə́ tɛ̀ɛ kɔ̂ mii wee-laa hâj khrɔ̂ɔp-khrua
雖然他工作多，但還是有時間給家人
Although he has a lot of work, he still makes time for family.
彼は仕事が多いけど、家族との時間も作る。
그는 많은 일을 하고 있지만, 여전히 가족을 위해 시간을 마련합니다.
มีเครื่องดื่ม เช่น ชา นม กาแฟ
mii khrʉ̂ang-dʉ̀ʉm chên chaa nɔɔ-mɔɔ kaa-fɛɛ

働くことは私たちを疲れさせる。
일하면 피곤해지죠.
